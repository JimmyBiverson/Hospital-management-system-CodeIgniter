Bayanno Hospital Management System

This project is a CodeIgniter hospital management system with role-based access and hospital administration features.

How the system works

  1. The app loads the login page and accepts an email and password.
  2. The login controller checks the submitted credentials against the admin, doctor, patient, nurse, receptionist, laboratorist, pharmacist, and accountant tables.
  3. When a match is found, the user session is created and the user is redirected to that role’s dashboard.
  4. Each dashboard performs its own CRUD operations for patients, appointments, prescriptions, invoices, lab work, staffing, or billing.
Important: This is a CodeIgniter application, not a Laravel app. Use a PHP server or a virtual host, not php artisan serve.

Setup

  1. Create your MySQL database.
  2. Update the database settings in application/config/database.php.
  3. Import the schema from uploads/install.sql.
  4. Optionally import demo_seed.sql to create the demo users.
